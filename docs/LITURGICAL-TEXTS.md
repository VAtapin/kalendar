# Богослужебная библиотека календаря

Стартовый корпус `public/data/liturgical-texts.json` содержит 98 текстов:
16 воскресных тропарей/кондаков восьми гласов, 14 текстов дней седмицы
(среда и пятница используют общую пару), 52 общих тропаря/кондака,
4 молитвы и 12 величаний двунадесятых праздников.
Это справочная библиотека, а не составитель службы. Полного годового круга,
полного молитвослова и полного сборника величаний в этой редакции нет.
Акафисты относятся к отдельной работе BibleDesktop.

## Источники и редакционный статус

- [Воскресные восемь гласов](https://azbyka.ru/molitvoslov/tropari-i-kondaki-voskresnye-vosmi-glasov.html).
- [Дни седмицы](https://azbyka.ru/molitvoslov/tropari-i-kondaki-dnej-sedmicy.html).
- [Общие тропари и кондаки](https://azbyka.ru/bogosluzhenie/tropari-i-kondaki-obshhie/) — только левая, церковнославянская колонка.
- [Утренние молитвы](https://azbyka.ru/molitvoslov/molitvy-utrennie.html) — «Царю Небесный», «Пресвятая Троице», «Отче наш», «От сна востав»; только молитвенный текст без толкований и номеров сносок.
- [Величания](https://azbyka.ru/velichanie) — церковнославянские величания двунадесятых праздников, без современных русских переводов.

Доступ проверен 9 сентября 2026 года. В корпус включены традиционные древние
церковнославянские богослужебные тексты, находящиеся в общественном достоянии,
а не современные русские переводы, толкования, аудиозаписи или оформление сайта.
Ссылка на веб-источник указывает происхождение транскрипции, а не лицензию на
копирование всех материалов страницы.

Язык — `cu`, запись — гражданская кириллица (`civil`), для воскресных и седмичных
текстов с ударениями (`civil-accented`). Это не реконструкция полного набора
старопечатных букв, титл и придыханий. Сохранены словесные варианты источника,
ударения и разделители `/`, `//`; HTML снят, пробелы нормализованы, латинские
омоглифы a/p заменены кириллическими а/р. В величаниях также нормализованы
латинские гласные с ударением (á/é/ó/É) в кириллицу с сохранением ударения.
Современные переводы не импортированы. В молитвах удалены номера сносок;
тексты сохранены целиком в границах соответствующей молитвы источника.

Все записи имеют `review.status = source-transcribed`: перенесены из источника,
но не прошли отдельную проверку богослужебным редактором. Это нельзя представлять
как статус `editor-reviewed`. Варианты кондаков вторника, четверга и субботы
сохранены именно по указанному седмичному сборнику; они не заменяют решение
о порядке конкретной службы. Общие тексты с `(имярек)` остаются шаблонами;
имена автоматически не подставляются. Дополнительный Богородичен после
«Слава, и ныне» и кондак с указанием «глас тот же» из общего источника не включены.

## Контракт

Корень: `schemaVersion: 1`, `version`, `contentHash` (SHA-256 от JSON.stringify(texts)),
`completeness`, `texts`. `version` меняется при редактировании; `contentHash`
позволяет обновить серверный кэш независимо от версии календарного XML.
Дополнительное `availability: {prayers: true, magnifications: true}` сообщает
о наличии записей, тогда как `completeness.prayers/magnifications: false`
означает незавершённость соответствующих корпусов. Эти признаки не противоречат
друг другу. У молитв и величаний `scope=common`, `tone=null`, `weekdays=[]`;
название праздника в `subject` — справочная тема, не привязка к календарной дате.

Каждая запись содержит:

| Поле | Значение |
| --- | --- |
| `id` | Стабильный идентификатор; существующие ID не перенумеровывать |
| `type` | `troparion`, `kontakion`, `prayer`, `magnification` |
| `title`, `text` | Русская справочная подпись и текст без HTML |
| `language`, `orthography` | `cu`; `civil` или `civil-accented` |
| `scope` | `resurrection`, `weekday`, `common` |
| `tone` | 1–8 или null; явный глас текста, не вычисленный глас даты |
| `weekdays` | 0 — воскресенье, 1 — понедельник, …, 6 — суббота; пустой массив у общих текстов |
| `subject` | Справочная тема; не идентификатор святого и не автоматическая привязка |
| `sources` | URL, название страницы, дата доступа |
| `rights` | Статус древнего текста и обоснование; не распространяется на веб-страницу целиком |
| `review` | Статус переноса/редакторской проверки и примечание |

Модуль `src/calendar/api/liturgical-texts.ts` экспортирует `listLiturgicalTexts`
и `getLiturgicalText`. Библиотека передаётся явно; модуль не обращается к сети,
файлам, текущему времени или календарному движку.

Фильтры `id`, `type`, `scope`, `tone`, `weekday`, `language`, `subject` объединяются
через AND. `weekday` выбирает только записи с явным вхождением в `weekdays`;
пустой массив не означает «применимо каждый день». Неизвестный ID или язык
не подменяется похожим текстом. Глас/день за пределами диапазона дают пустой список.
Параметр `date` намеренно отсутствует: совпадение названия праздника, дня недели
или вычисленного гласа само по себе не устанавливает положенные песнопения.

Проверка: `npx vitest run tests/liturgical-texts.spec.ts`.

## HTTP API и WordPress

`GET /api/v1/calendar-texts/` — защищённый тем же API-ключом и квотой календаря
справочник. Поддерживает GET/HEAD/OPTIONS, ETag/304 и разрешённый прикладной кэш
300 секунд. Фильтры HTTP: `id`, `type`, `scope`, `tone`, `weekday`, `language`;
`subject` доступен только в чистом TypeScript-модуле. Неверный параметр даёт 400,
неизвестный ID — 404, язык без текстов — пустую выдачу. Назначения по `date` нет.
Ответ дополнен `assignment: reference-only`, `language`, `count`; для
календарного плана службы используется `/api/v1/calendar/service`.

Пример: `/api/v1/calendar-texts/?type=troparion&scope=resurrection&tone=1`.
WordPress получает корпус с сервера календаря, показывает источники, статус
проверки, фильтры и копирование. В ZIP полный корпус не дублируется.
Маршрут подготовлен локально; доступ на рабочем сервере появится после обычного
развёртывания кода и JSON. HTTP-проверки: `node scripts/test-calendar-public-api.mjs`.
