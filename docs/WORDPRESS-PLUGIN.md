# WordPress-плагин Georg-Kloster Calendar Workshop

Версия 1.3.75 получает календарь, тексты, переводы и иконы только из API Bible Desktop.
В Kalendar календарный HTTP API удалён. Существующие шорткоды, блоки Gutenberg,
темы, все наборы оформления поста и галерея икон сохранены.

## Обновление

1. Сначала обновить Bible Desktop и проверить его день, месяц, год и остальные
   используемые ответы по [контракту](CALENDAR-HTTP-API.md).
2. Скачать `/downloads/orthocal-1.3.75.zip` на сайте Kalendar и установить в WordPress.
3. В «Подключении» указать `https://bible-desktop.com` без `/api`.
4. Проверить конструктор, страницу с шорткодами, чтения и галерею.

Константа `ORTHOCAL_API_ORIGIN` больше не используется. Старый ключ Kalendar
сохранён как неактивная настройка, но не отправляется Bible Desktop. Календарные
запросы публичные и ограничиваются на стороне поставщика.

## Ресурсы и сборка

Все 16 оформлений и общие декоративные PNG подготовлены из существующих ресурсов до 384 px
и включены в плагин. Знаки Типикона и Monomakh Unicode с SIL OFL также включены;
они не требуют удалённого сервера. Иконы Bible Desktop кэшируются отдельно,
с сохранением ограничений размера, подписанного источника и лимита 200 МБ.

```bash
node scripts/build-wordpress-plugin.mjs --publish-downloads
```

Сборщик сначала готовит декоративные ресурсы, проверяет PHP (при заданном
`ORTHOCAL_PHP_BINARY`) и JS, затем создаёт один ZIP в `artifacts` и `public/downloads`.
Домен и ключ не включаются в архив как пользовательские данные.

## Проверка

```bash
node scripts/test-wordpress-plugin.mjs
node scripts/test-web-calendar.mjs
node scripts/test-calendar-api-docs.mjs
```

Первый сценарий использует одноразовый настоящий WordPress/SQLite из
`tmp/orthocal-wp/wordpress`. Годовой fixture генерируется существующим ядром
BibleDesktop из соседнего checkout; путь можно задать `BIBLE_CALENDAR_RUNTIME`.
Это тестовый источник, он не упаковывается и не запускается production-плагином.
Проверяются серверный рендер, безопасный медиакэш, навигация, чтения и все
оформления. Скриншоты можно направить в отдельную папку `ORTHOCAL_TEST_ARTIFACTS`.

Исходный публичный репозиторий плагина — `VAtapin/wp_orthodox_calendar`.
Новый tag/release и WordPress.org SVN в этой миграции автоматически не создаются.

## Повторная проверка WordPress.org — 1.3.72

JS/CSS отформатированы как читаемые оригинальные исходники и включены в ZIP без сборки/минификации. Readme указывает публичный репозиторий и assets; его README описывает проверки и упаковку. Все короткие transient-ключи oc_ заменены на orthocal_response_, orthocal_cooldown_, orthocal_rate_ и orthocal_media_rate_; настройки и шорткоды сохранены. Рендер постных периодов проверяет year/month/day, реальную дату и порядок границ; повреждённые периоды пропускаются без предупреждений.

## Plugin Check — 1.3.73

Публичная дата и REMOTE_ADDR проходят wp_unslash, очистку и проверку формата; некорректные значения и массивы отклоняются. Публичная дата и вкладка админки используются только для чтения. Узкие исключения с объяснением оставлены для этих GET-параметров, стандартной DONOTCACHEPAGE и свежего списка метаданных медиакэша. Переводы сохранены по решению владельца.

## Проверенный каталог молитв — 1.3.74

Сначала опубликовать BibleDesktop `34e7e820` по его `docs/PRAYER_CATALOG.md`.
Плагин использует 24 канонических произведения (21 видимая карточка), группы
`short/rules/occasions/initial` и `prayer_groups` для нескольких применений одного текста.
Сохранённые `work="prayer-N"` разрешаются через `legacy_slugs`; скрытые начальные
молитвы доступны по прежним прямым ссылкам. Язык выбирается из реальных редакций;
при явно недоступном языке показывается сообщение, немецкие источники — внешние ссылки.
Русский оригинал Оптинских старцев доступен отдельно; автоязык конкретной ссылки
учитывает доступные редакции этого произведения.

Молитвенного offline-пакета здесь нет. WordPress transient/memo кэш отделён
версией плагина от прежних копий; ревизия произведения входит в ключ запроса текста.
Каталог и версии кэшируются не более 300 секунд. После установки ZIP 1.3.74
очистить CDN/полностраничный кэш страниц с календарём, затем проверить старую
ссылку, группы, полные правила, языки молитв и богослужебные чтения.
Регрессия нового контракта включена в `node scripts/test-wordpress-plugin.mjs`
и читает проверенный пакет из соседнего checkout BibleDesktop.

## Зачала в чтениях — 1.3.75

После публикации справочника BibleDesktop `fbee50ed` чтения дня показывают номер
зачала рядом с исходной книгой/стихами только при `exact-reference-match`
и единственном сочетании книги/номера. Варианты источника сохраняются в раскрываемом
списке ссылок. Для `ambiguous` показываются все возможные соответствия без выбора
первого; `unmatched` и прежний API остаются без номера.
Указана граница проверки: координаты относятся к источнику, сопоставление
стихов других переводов не подтверждено. Календарные правила и выбор перевода
не меняются. Сначала backend import/check, затем публикация Kalendar и ZIP 1.3.75.
