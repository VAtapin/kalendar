# Пакет изменений по семи направлениям

## 1. Словари редактора

Добавлены отдельные адаптеры корпусов для браузера и Node. В браузере словари
DE/CU/UK/PL загружаются динамически по выбранному языку и сохраняются в памяти.
Параллельные запросы одного языка объединяются. Сервер, CLI и существующие
проверки корпуса сохраняют синхронный доступ ко всем данным.

Загрузка календаря и PDF явно ожидают нужный словарь. Поздний ответ смены языка
не заменяет более поздний выбор; загрузка данных другого проекта также защищена
счётчиком запросов. Содержимое каждого словаря сравнивается с серверной версией
полностью, а не по нескольким примерам.

Исходный чанк редактора около 2 МБ больше не содержит все словари. Каждый язык
имеет собственный файл. Украинский корпус около 556 КБ ещё вызывает предупреждение
Vite: это данные выбранного языка, а не обязательная загрузка каждого посетителя.
Порог предупреждения не повышен.

Статические зависимости редактора вместе с точкой входа уменьшились с
2 606 771 до 730 998 байт; расчётный gzip — с 660 697 до 224 721 байт.
Это около 72% экономии до загрузки выбранного языка. Главная остаётся около
222 КБ JavaScript. Размеры не включают изображения, шрифты и ответы API.

## 2. PDF и сервер

PDF сохраняет fontkit и pdf-lib и загружается по запросу экспорта. Его чанк
остаётся около 1,17 МБ, gzip 517 КБ. Удаление поддержки встраивания шрифтов не
используется как оптимизация. Экспорт ждёт выбранного календарного словаря.

Локальные измерения холодного серверного расчёта 2026 года:

| Язык | Время | RSS процесса после расчёта |
|---|---:|---:|
| ru | 300 мс | 140 МБ |
| de | 438 мс | 161 МБ |
| cu | 531 мс | 182 МБ |

Это измерения рабочей машины, не обещание скорости Plesk. RSS включает весь
Node-процесс. Годовой JSON — примерно 6–7 МБ; браузерные дневные/месячные ответы
нельзя путать с этим внутренним результатом серверного расчёта.
Benchmark: разбор XML 82 мс, десять лет 1 260 мс, 4 380 ячеек макетов 1 050 мс.
Существующие бюджеты benchmark выполнены.

## 3. Структура редактора

Из `App.vue` выделены:

- история, отмена/повтор и управление ресурсами снимков — `use-project-history.ts`;
- последовательное серверное сохранение, ревизии и защита от старых ответов —
  `server-project-saver.ts`;
- построение меню и его состояние — `application-menus.ts`.

Число строк `App.vue` уменьшилось с 5 043 до 4 812. Он всё ещё большой: это
выделение конкретных обязанностей, а не полное переписывание редактора.
Тесты проверяют сохранение изменений во время запроса, очередность ревизий,
смену контекста, undo/redo и сохранение настройки языка интерфейса.

## 4. Переводы

Меню теперь запрашивает переводы явно при построении. Немецкий словарь
веб-календаря вынесен в `calendar-ui/web-calendar-i18n.js`. Новое пояснение
неполных назначений Часослова добавлено в словарь WordPress.
Сохранено различие между языком интерфейса и церковнославянским текстом.
Остальные старые компоненты пока используют совместимый DOM-переводчик;
перенос каждого оставшегося экрана на явные ключи остаётся последовательной
дальнейшей работой, а не выполненной массовой заменой.

## 5. Общие модули

Две галереи используют один JS и CSS; страница Богородицы задаёт свой начальный
фильтр. Веб-календарь разделён на HTML, CSS, JS и словарь, его код отформатирован.
Три обращения к Bible Desktop используют общий транспорт, сохраняя отдельную
проверку схем и разное поведение при недоступности изображений и службы.
Для HTML и стабильных URL модулей добавлена повторная проверка кэша; отсутствующий
`calendar-ui`-ресурс возвращает 404, а не HTML главной страницы.

## 6. Иконы и Часослов

В Bible Desktop добавлены три проверенные связи: Андрей Тотемский, Василий
Московский, Григорий Армянский. Проверены источник, различающее именование и
фиксированная дата. Все три карточки существуют в production API и пока не
имеют связей. После применения ожидаются 140 подтверждённых карточек вместо 137
на проверенном наборе. Новая партия скачиваемых икон не импортируется.

В Часослове исправлена потеря порядка: назначенные тексты теперь возвращаются
в порядке уставного плана, затем справочные. Веб-календарь и WordPress отображают
перед назначенным текстом его `rubric`, например «Слава:». Неполные назначения
отмечаются отдельным пояснением. Новые неподтверждённые правила годового круга
ради увеличения покрытия не добавлялись.

## 7. Проверки и выпуск

- Kalendar: 71 файл / 521 тест; TypeScript и production build.
- Контроль сборки: главная не получает корпуса/PDF; редактор не получает их
  статически и укладывается в бюджет 1 МБ до выбора языка.
- Browser: открытие редактора, меню, изменение формата и undo; загрузка только
  выбранного языка и защита от запоздавшего выбора; чистые URL и история переходов.
- Веб-календарь: день/неделя/месяц/год, шрифты, немецкие подписи, недоступность
  службы, назначенная уставная помета, закрытие окна.
- WordPress: полный локальный WordPress/SQLite + Edge, 20 блоков, Gutenberg,
  сохранение настроек, чтения, кэш, вложенные окна; отдельный тест немецкого Часа.
- Bible Desktop: 27 тестов / 278 проверок Часов и связей; 26 проверок runtime.

Плагин выпущен как 1.3.34. Серверное обновление пользователь выполняет отдельно;
локальные проверки не означают, что новая версия уже развёрнута в production.
