# Украинский и польский: перевод календарных текстов

## Объём

Обычный перевод текущего русского корпуса на украинский и польский по запросу пользователя. Это не новая независимая историческая или богослужебная аттестация.

- Полные названия всех 2565 записей памятей: 2532 уникальных исходных названия на каждом языке.
- Все 41 уникальная подпись к библейским чтениям.
- Дополнительные полные и краткие названия переходящего цикла, создаваемые программой.
- Короткие формы для печатных ячеек образуются из переведённого полного названия. Очень короткая форма может сокращаться с явным многоточием; полный ответ API сохраняет полный текст.
- Добавлены переводы правил поста и венчания, названий книг во всех 1205 библейских ссылках. Сами библейские стихи здесь не хранятся и не переводились; главы и номера стихов сохраняются.

XML и календарные расчёты не изменялись. Немецкие и церковнославянские словари не изменялись. Неизвестный пользовательский текст по-прежнему возвращается с честной отметкой `source-fallback`, а не выдаётся за перевод.

## Хранение и воспроизводимость

Исходные переводы находятся в `scripts/data/uk-pl-translations.json` и пяти `uk-pl-part-*.json`. Каждая строка содержит индекс исходной записи XML, украинский и польский тексты. Индексы закреплены SHA-256 исходного XML:

`8c1bef82656a0b39cd3d4ac8ffc33fc35f1ef123a728df93344931e914cf8ff4`

Команда `npx tsx scripts/build-uk-pl-translations.ts` объединяет части в `src/calendar/localization/uk-commemorations.json` и `pl-commemorations.json`. Для повторяющихся одинаковых русских названий выбирается перевод самой ранней записи XML. Генератор отклоняет пропущенные названия, дубли индексов, изменённые арабские числа/римские века и кириллицу в польском тексте.

Календарь и публичный API используют один механизм локализации. Русские `sourceTitle` и исходная запись XML в диагностическом ответе API остаются русскими намеренно: это данные происхождения, а не отображаемый перевод.

## Проверка

Итог 09.09.2026: для UK и PL `source-fallback = 0` среди всех 3815 XML-записей и названий памятей в построенных календарях 2026/2027. Все 506 тестов (64 файла) прошли. Проверка TypeScript и production-сборка прошли. Сборка предупреждает о крупных JS-чанках; это не ошибка перевода или сборки.

Тест `tests/uk-pl-translations.spec.ts` проверяет покрытие всего XML, сохранение чисел, подключение точных словарей и поведение неизвестного текста. Общие тесты API сравнивают отображаемые полные и краткие названия, а также описания с редактором для всех дней 2027 года. `scripts/audit-calendar-localization.ts` отдельно показывает покрытие XML и календарей 2026/2027.

Проверка покрытия не является гарантией безошибочности каждого языкового оборота. Углублённая сверка переводов по внешним церковным источникам для этих двух языков намеренно не выполнялась, согласно просьбе пользователя.
