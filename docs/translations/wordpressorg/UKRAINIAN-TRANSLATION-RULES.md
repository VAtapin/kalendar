# Український переклад WordPress

Перевірено 12.10.2026 перед публікацією виправлень для версії 1.3.78.
Офіційні джерела: [глосарій](https://translate.wordpress.org/locale/uk/default/glossary/)
та [команда локалізації](https://make.wordpress.org/polyglots/teams/?locale=uk).

- Зберігати усталену термінологію WordPress: плагін, налаштування, запис,
  бічна колонка, попередній перегляд, короткий код, виринаюче вікно,
  бібліотека медіа, частина посилання (slug), початковий (default).
- У прямих інструкціях використовувати узгоджене звертання на «ви»:
  виберіть, відкрийте, змініть. Кнопки — зрозумілі назви дій.
- Не змінювати назви WordPress, плагіна й сервісів. Ікони в календарі —
  релігійні зображення; глас, Типікон і зачало — богослужбові терміни.
- Назви місяців у датах і заголовках мають різні gettext-контексти;
  не змішувати «січня» з «Січень».
- Зберігати URL, команди, шляхи, HTML, параметри, короткі коди й підстановки.
  Технічний формат API `YYYY-MM-DD` не замінювати на `РРРР-ММ-ДД`.
- Зберігати пробіли на межах склеюваних фрагментів; між числом і МБ/КБ
  використовувати нерозривний пробіл. Узгоджувати рід і число зі справжнім
  контекстом: «часовий пояс — змініть його», «зображення та шрифти».

Каталоги: `stable-1.3.78-uk.po` (441 рядок інтерфейсу) та
`stable-readme-1.3.78-uk.po` (67 рядків опису). Перевірка:

```bash
node scripts/check-wordpress-ukrainian-translations.mjs
```

Після імпорту з PTE-правами зі статусом Current перевірити всі чотири
гілки: Stable, Development і обидва Readme. Порівняти Current-експорти
з перевіреними файлами, перевірити лічильники й API мовних пакетів.
Наявність пакета не означає, що він уже містить щойно затверджені зміни:
перевіряти час оновлення та вміст PO у ZIP.

Виправлення публікуються через WordPress.org. Вбудовані каталоги та ZIP
плагіна цим завданням не змінюються. Пошкоджені стрілки й застарілі
відомості в англійському Readme потребують окремого виправлення джерела;
переклад не має самостійно змінювати описану функціональність.
