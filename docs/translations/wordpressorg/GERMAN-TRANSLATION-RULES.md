# Немецкие переводы WordPress

Для Georg-Kloster Calendar Workshop сверять немецкий перевод не только с
английским original, но и с [глоссарием](https://translate.wordpress.org/locale/de/default/glossary/)
и [Style Guide немецкой команды](https://de.wordpress.org/team/handbook/polyglots-team/style-guide/).
Повторно проверены 12.10.2026 перед утверждением. При следующих изменениях сверять актуальные правила.

- `de/default` — обращение `du`, строчные местоимения; `Sie` допускается только
  в отдельном `de/formal`. Кнопки и меню — инфинитив, инструкции — повелительная форма.
- Website — весь сайт; Seite — отдельная страница. Benutzer, Benutzername,
  Konto, Beitrag, Inhaltstyp, Titelform, Abschnitt, Tab, Pop-up — терминология WordPress.
- Названия плагина, WordPress и внешних сервисов сохранять. `Theme` WordPress
  отличать от оформления календарного блока (`Design`). Религиозные иконы
  (`Ikonenbilder`) отличать от пиктограмм интерфейса (`Icons`/`Symbole`):
  строка `Icon` в assets/calendar.js относится к изображению религиозной иконы.
- Использовать понятные активные предложения без разговорных сокращений;
  родовой мужской род в интерфейсе, без приписывания программе чувств и намерений.
- Кавычки „…“, `und` вместо `&` в обычном тексте, немецкие числовые форматы,
  неразрывные пробелы перед единицами, многоточием и тире. Технические значения,
  даты в обязательном формате API, URL, HTML, команды, шорткоды и подстановки
  не локализовать. Пробелы на границах склеиваемых фрагментов сохранять.

Актуальные файлы для загрузки: `stable-1.3.78-de.po` (441 строка интерфейса)
и `stable-readme-1.3.78-de.po` (67 строк описания). Первым файлом обновлять
Stable и Development, вторым — Stable Readme и Development Readme в `de/default`.
Без PTE-прав импорт создаёт предложения Waiting. С PTE-правами проверенные
каталоги можно импортировать со статусом Current; предупреждения проверять отдельно.
12.10.2026 все четыре ветки утверждены полностью: UI 441/441, Readme 67/67,
Waiting/Untranslated/Fuzzy/Changes requested/Warnings — 0. Все четыре Current-экспорта
совпадают с проверенными файлами. Подтверждение: `german-approval-1.3.78-receipt.json`.

Проверка перед импортом:

```bash
node scripts/check-wordpress-german-translations.mjs
git diff --check
```

В этой задаче исправлены файлы предложений GlotPress. Опубликованный ZIP 1.3.78
и встроенные языковые файлы плагина не меняются: синхронизация встроенного
немецкого каталога с принятыми редакторами переводами относится к следующему выпуску.
Известные повреждённые стрелки в английских Readme originals и устаревшая фраза
о неподключённых акафистах не исправляются изменением original в PO: это требует
обновления английского readme в исходниках и синхронизации WordPress.org.
