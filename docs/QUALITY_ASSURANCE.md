# Проверка качества

Проект использует четыре уровня автоматической проверки.

1. `npm test` — календарные правила, приоритеты памятей, геометрия, хранилище,
   предпечатная проверка, PDF/X и публичный API.
2. `npm run test:e2e` — рабочий сценарий редактора: безопасное создание 13
   страниц и независимое управление объектами внутри дня (в том числе 6 и
   100 pt без скрытого максимума), фактический CSS-размер текста, автоподбор,
   знак типикона и сохранение/применение отдельного шаблона сетки.
3. `npm run test:visual` — все 12 месячных страниц PDF рендерятся Poppler и
   сравниваются с утверждёнными растровыми эталонами. Эталоны обновляются явной командой
   `npm run test:visual:update` после визуальной проверки.
4. `npm run benchmark` — разбор XML, построение десяти лет и компоновка матрицы
   12 месяцев × A3/A4/A5/A6 × 3 шаблона проверяются по бюджету времени.

Отдельный тест `calendar-quality-matrix.spec.ts` прогоняет все 144 комбинации и
проверяет высоту строк, отсутствие пересечения сетки с легендой, обязательные
праздники и относительный размер стандартного знака поста.

Перед выпуском выполняются:

```bash
npm run typecheck
npm test
npm run test:e2e
npm run test:visual
npm run benchmark
npm run build
```
