# Знаки Типикона

Отсутствие праздничного знака — самостоятельный случай, а не шестеричная служба.
Сопоставление кодов используемого MemoryDays.xml:

| Код | Знак |
| --- | --- |
| 0–2 | Великий праздник |
| 3 | Бденный |
| 4 | Полиелейный |
| 5 | Славословный |
| 6 | Шестеричный |
| 7 и остальные / неизвестные коды | Без знака |

Экран и PDF используют общий выбор высшего явно заданного ранга среди событий дня.
Порядок и сокращение видимого текста не меняют знак. Воскресенье, попразднство или
пользовательское выделение монастырского события сами по себе не создают знака.
При этом в тот же день может быть другая память с явно заданным рангом.

Регрессионные проверки: 3 и 4 февраля 2027 без знака, 15 февраля — великий праздник,
16 февраля — шестеричная память Симеона Богоприимца и Анны пророчицы из исходных данных.
Проверяются также неизвестные коды и независимость от порядка событий.

Это исправление механизма отображения, а не утверждение о полной независимой
богослужебной экспертизе каждой записи исходного месяцеслова.
