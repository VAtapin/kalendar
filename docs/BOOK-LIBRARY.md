# Самостоятельное чтение книг

Режим `view=books` находится в существующем `/web-calendar`. Он не запрашивает
календарь, service templates или assignments и не использует дату/храм для
выбора текста. Кнопка «Книги» доступна рядом с «Богослужение сегодня».

## Только опубликованная точная редакция

- Каталог: `GET /api/liturgical/works?language=cu`.
- Текст: `GET /api/liturgical/works/{slug}/versions/cu?edition={exact-code}`.
- Читатель допускает только каталоговые CU/traditional редакции и проверяет
  slug, edition, orthography, reader profile, уникальные blocks и segments.
- Ошибки 404/409/403/429 и отсутствие редакции в каталоге не вызывают подстановку
  другого языка, редакции или книжного текста из Kalendar.
- Для source-book используются действующие серверные whole-source guards и
  метаданные sourceReviewBasis/bookCompleteness/sourceScope. Флаги
  appointedForDate=false и cleanTemplate=false нормальны для книжного источника.

Копий книг, реестра 367 глав, локального корпуса и дополнительного backend нет.
Тексты живут в памяти текущего читателя и удаляются при выходе. Все запросы
без credentials и с no-store; переключение отменяет запрос и старую отрисовку.

## Выбор и навигация

Минеи выбираются по месяцу/номеру главы из опубликованного каталога. Новые
`whole-cu-minea-MM-D` распознаются по идентификатору; старые идентичности — по
однозначному опубликованному адресу главы Азбуки веры. Неопознанные старые
книги не теряются: остаются среди «Других книг и текстов» с исходным названием.
Номер главы не преобразуется в гражданскую дату и не ограничивается правилами
календаря. Поле `collections` не требуется: текущий annual каталог может
возвращать пустой список коллекций.

Октоих читается целиком либо по выбранному гласу. Восемь гласов включаются
только при однозначных восьми упорядоченных заголовках опубликованного текста;
явные строки окончания ограничивают раздел, отдельные приложения остаются
доступны в «Весь источник». День недели — переход к дословному заголовку внутри
открытого гласа, а не составление или фильтрация службы дня.

Есть поиск по названиям/редакциям каталога, оглавление, возврат к нему и размер
текста. Поиск снимает диакритику только со своей строки сравнения. Исходные
слова, стили и CU-заголовки не переводятся и не нормализуются при показе.
«Другие книги и тексты» могут содержать короткие опубликованные фрагменты:
reader_profile=full не используется как доказательство полноты целой книги.

## Длинный текст, печать и снимок документа

DOM добавляется порциями по 120 блоков. Пока весь выбранный диапазон не показан,
печать отключена и `getDocument()` возвращает null. Печать использует уже
показанный body, ждёт document.fonts.ready и проверяет актуальность выбора.
Настройки A4/полей/шрифтов существующего читателя сохранены. Физическая
пагинация и скорость на устройствах не утверждаются без браузерной проверки.

`createBookReader().getDocument()` отдаёт независимый снимок формата PDF-читателя:
kind=book, title/subtitle/status, information, sources, blocks с runs/rubric/CU,
navigation/contents и sourceMetadata с точной редакцией и выбранным диапазоном.
Снимок содержит только реально открытые блоки; изменение снимка не меняет
читатель. В нём нет date/temple/service missing. warnings пуст: книжный текст
не получает предупреждений о неполноте службы дня. complete в общем формате
является полем полноты дневной службы и для kind=book не означает неполную книгу.
Ограничение выбранного гласа отмечено обычным information, не красным daily warning.
Кнопка скачивания PDF подключается отдельным изменением.

## Проверки

```bash
npm test -- tests/book-library.spec.js tests/book-reader.spec.js
node scripts/test-book-library.mjs
```

Вторая команда только читает public API и проверяет Node-представление книги:
точные тексты всех блоков Минеи, полного Октоиха и другого текста, восемь гласов,
отсутствие daily warnings. Браузер и production-данные не изменяются.
Опциональный `--witness <TraditionalCuOctoechosOfficeIndexPins.json>` сравнивает
хеши исходных заголовков с независимым локальным witness; research helper
никогда не подключается в HTTP/runtime Kalendar.
