# Самостоятельное чтение книг

Режим `view=books` находится в существующем `/web-calendar`. Он не запрашивает
календарь, service templates или assignments и не использует дату/храм для
выбора текста. Кнопка «Книги» доступна рядом с «Богослужение сегодня».

## Только опубликованная точная редакция

- Каталог: `GET /api/liturgical/works?language=cu`.
- Текст: `GET /api/liturgical/works/{slug}/versions/cu?edition={exact-code}`.
- Читатель допускает только каталоговые CU/traditional редакции и проверяет
  slug, edition, orthography, reader profile, уникальные blocks и segments.
- Ошибки 404/409/403/429 и отсутствие редакции в каталоге не вызывают подстановку
  другого языка, редакции или книжного текста из Kalendar.
- Для source-book используются действующие серверные whole-source guards и
  метаданные sourceReviewBasis/bookCompleteness/sourceScope. Флаги
  appointedForDate=false и cleanTemplate=false нормальны для книжного источника.

Копий книг, реестра 367 глав, локального корпуса и дополнительного backend нет.
Тексты живут в памяти текущего читателя и удаляются при выходе. Все запросы
без credentials и с no-store; переключение отменяет запрос и старую отрисовку.

## Выбор и навигация

Минеи выбираются по месяцу/номеру главы из опубликованного каталога. Новые
`whole-cu-minea-MM-D` распознаются по идентификатору; старые идентичности — по
однозначному опубликованному адресу главы Азбуки веры. Неопознанные старые
книги не теряются: остаются среди «Других книг и текстов» с исходным названием.
Номер главы не преобразуется в гражданскую дату и не ограничивается правилами
календаря. Поле `collections` не требуется: текущий annual каталог может
возвращать пустой список коллекций.

Длинные главы Минеи открываются частями через то же оглавление и кнопки
«Предыдущий/Следующий раздел», что и Октоих. На странице и в PDF — максимум
80 блоков и 18 000 знаков (один неделимый исходный блок сохраняется целиком).
Короткие главы открываются целиком. Ссылки `bookPart` восстанавливают часть
точной редакции; глас и день недели для Минеи не показываются.
API по-прежнему возвращает весь текст выбранной главы/книги одним ответом:
ограничены отрисовка и экспорт, сетевой постраничной выдачи этот контракт не даёт.

Октоих читается небольшими частями: глас (либо предисловие/приложения) →
день недели печатной книги → служба/раздел. По умолчанию открывается первая
служба субботы первого гласа, а не вся книга или глас. Старые ссылки на глас
открывают первую подходящую часть. Восемь гласов определяются только по
однозначным восьми упорядоченным исходным заголовкам. День недели — часть
книжной навигации, не гражданская дата или назначение службы дня.

Разделы начинаются у исходных заголовков служб; длинные службы дополнительно
делятся у напечатанных канонов/песней/стихословий. Максимум части — 80 блоков
и 18 000 знаков (единственный неделимый исходный блок не разрезается).
Без подходящего заголовка используется последовательная нумерованная часть;
слова, порядок и сами blocks не меняются. Предисловие, начала гласов, промежуточные
строки и приложения не теряются: полное разбиение покрывает исходник без
перекрытий и пропусков. В текущей опубликованной редакции — 409 частей.

Закреплённая панель даёт «Предыдущий/Следующий раздел» и быстрое оглавление;
в оглавлении есть ссылки на любую часть. `bookPart=s<source-block-index>`
вместе с точной book/edition сохраняет выбранный диапазон. Явные переходы
создают записи history; reload/deep-link/Back восстанавливают выбор через
существующий читатель. Новая часть отменяет старую отрисовку и PDF; печать
и PDF содержат только открытый диапазон с подписью гласа/дня/раздела.

Есть поиск по названиям/редакциям каталога, оглавление, возврат к нему и размер
текста. Поиск снимает диакритику только со своей строки сравнения. Исходные
слова, стили и CU-заголовки не переводятся и не нормализуются при показе.
«Другие книги и тексты» могут содержать короткие опубликованные фрагменты:
reader_profile=full не используется как доказательство полноты целой книги.

## Длинный текст, печать и снимок документа

DOM добавляется порциями по 120 блоков. Пока весь выбранный диапазон не показан,
печать отключена и `getDocument()` возвращает null. Печать использует уже
показанный body, ждёт document.fonts.ready и проверяет актуальность выбора.
Настройки A4/полей/шрифтов существующего читателя сохранены. Физическая
пагинация и скорость на устройствах не утверждаются без браузерной проверки.

`createBookReader().getDocument()` отдаёт независимый снимок формата PDF-читателя:
kind=book, title/subtitle/status, information, sources, blocks с runs/rubric/CU,
navigation/contents и sourceMetadata с точной редакцией и выбранным диапазоном.
Снимок содержит только реально открытые блоки; изменение снимка не меняет
читатель. В нём нет date/temple/service missing. warnings пуст: книжный текст
не получает предупреждений о неполноте службы дня. complete в общем формате
является полем полноты дневной службы и для kind=book не означает неполную книгу.
Ограничение выбранного гласа отмечено обычным information, не красным daily warning.
«Скачать PDF» создаёт настоящий A4 PDF с встроенными DejaVu/Ponomar,
рубриками, компактным векторным восьмиконечным крестом, оглавлением и закладками.
Источники, URL, коды произведений/редакций и отдельные подписи издания не
показываются в читателе, печати и PDF; библиография и sourceMetadata в свойства
PDF не записываются. Внутренние метаданные и проверки точной редакции сохраняются.
Экспортируется только открытый источник/раздел и точная редакция. Необязательный
комментарий явно подписан как пользовательский, остаётся в памяти и не меняет
книжный текст. Подготовка PDF показывает progress;
показаны обработанные блоки и отмена. Смена выбора, комментария или читателя
отменяет текущий экспорт. До полной отрисовки кнопка отключена.

Модуль PDF загружается лениво по `/calendar-ui/worship-pdf-manifest.json`.
`build-production.ts` собирает его в staging до публикации; manifest указывает
на content-addressed `/assets/worship-pdf-<hash>.js`. Старые versioned assets
сохраняются штатным publishBuild. Зависимости не добавлены. Нативная печать
осталась отдельной кнопкой. В читателе служб PDF захватывает только основной
article, предупреждения и обязательные пробелы; условные варианты отдельно
не присоединяются. Только `kind=dated-service` имеет предупреждение о неполном
дневном составе. Книжный PDF не получает дату/храм/дневные placeholders.

## Проверки

```bash
npm test -- tests/book-library.spec.js tests/book-sections.spec.js tests/book-reader.spec.js tests/reader-pdf-controls.spec.js tests/worship-pdf.spec.ts tests/worship-pdf-browser.spec.ts
node scripts/test-book-library.mjs
# После npm run build:
node scripts/test-worship-pdf-build.mjs
```

Вторая команда только читает public API и проверяет Node-представление книги:
точные тексты Минеи и другого текста, побайтную сохранность разбиения всех
14 059 блоков Октоиха, snapshot каждой его части, восемь гласов/приложения,
отсутствие daily warnings. Браузер и production-данные не изменяются.
Опциональный `--witness <TraditionalCuOctoechosOfficeIndexPins.json>` сравнивает
хеши исходных заголовков с независимым локальным witness; research helper
никогда не подключается в HTTP/runtime Kalendar.
