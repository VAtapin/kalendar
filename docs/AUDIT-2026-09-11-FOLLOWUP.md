# Проверка календаря, WordPress и Bible Desktop — 11 сентября 2026

Проверка продолжает изменения 9–11 сентября. Оценивалось фактическое поведение и результаты тестов, а не инструмент, которым написан код. Серверные команды в этой задаче не выполнялись. Новые партии скачанных икон не импортировались.

## Подтверждённые дефекты и исправления

- В WordPress `array_filter` удалял строку `"0"` из выбранных уровней: Пасха и великие праздники пропадали даже при выборе всех уровней. Фильтр теперь удаляет только пустые строки. Подготовлен плагин 1.3.33.
- В веб-календаре CSS-класс передавался как текст: `month-grid`, `event-card` и другие служебные имена выводились посетителю, сетки месяца/недели/года не получали оформление. Исправлены аргументы создания элементов.
- Объект стиля дня выводился как `[object Object]`. Теперь показывается название ранга.
- Сбой API богослужебных текстов препятствовал открытию самого дня. Календарная карточка теперь открывается независимо, с сообщением о недоступных текстах.
- Поздние ответы могли заменить более новые данные. Добавлены номера запросов; закрытие окна отменяет применение старого результата.
- Переход с 31 января на следующий месяц мог попадать в март. День ограничивается последним числом целевого месяца.
- Славянский шрифт не применялся к сеткам и оставался после смены языка в карточке. Применение языка исправлено; немецкие подписи веб-календаря дополнены.
- Иконы дня выводились только названиями. Теперь отображаются изображения и доступные описания.
- Справочные седмичные тексты выглядели назначенными службе. Для неназначенных вставок добавлена явная подпись.
- Kalendar выбирал иконы по числу и месяцу, обходя календарные связи. Теперь он читает разрешённые для конкретной даты иконы из `/api/calendar/day` Bible Desktop и проверяет дату ответа.

## Иконы и Часослов в Bible Desktop

`resources/imports/reviewed-icon-links.json` содержит 55 явных связей для 44 ранее несопоставленных карточек. Сохранены URL и хеш ключа источника, точные названия обеих записей, совпавшие даты и хеш календарного XML. Переводы строк нормализуются перед хешированием, чтобы Windows и Debian давали одинаковый результат. Используются точные именованные участники общей памяти; одно совпадение слова «Владимирская» или «Знамение» не принимается.

Команда `calendar:audit-icon-links --apply` применяет эти связи к существующей базе без повторного ZIP и без удаления старых связей. После применения ожидаются 137 связанных карточек вместо 93 на проверенном серверном снимке. Это не полная готовность всей библиотеки.

Часослов получил классификацию режима: обычные, Пасхальные, Царские, великопостные и дни Страстной седмицы. Обычный план вставок не применяется к специальным режимам. В читателе виден требуемый режим и пояснение. Классификация НЕ заменяет полный текст специального последования и все правила сочетаний праздников.

Основания: [Пасхальные Часы](https://azbyka.ru/bogosluzhebnye-ukazaniya?date=2026-04-12), [перенос Царских Часов](https://patriarchia.ru/bu/2026-01-18), [виды Часов](https://azbyka.ru/chasy). Граница Светлой субботы учитывает отдельный девятый Час.
