# Состояние проекта

## Реализовано

- Основной календарный сайт и публичный API работают из репозитория `Kalendar`.
- WordPress-плагин опубликован в версии 1.3.38.
- Версия 1.3.39 собрана; предпросмотр защищён от запоздалых ответов при выборе картинок, устранена автоматическая подмена `cu` на `cu-civil`.
- Версия 1.3.40 подавляет картинку поста при `no-fast` и проверяет все наборы на постной дате.
- Версия 1.3.41 заменяет относительный размер картинок поста вводом высоты в пикселях; ширина рассчитывается браузером по пропорциям. Старые `small`, `medium`, `large` сохранены для уже вставленных шорткодов.
- Версия 1.3.42 размещает управление переводом и размером чтений либо на странице, либо внутри всплывающего окна в соответствии с `reading_open`; ползунок работает в обоих режимах.
- Версия 1.3.43 выводит перед текстом чтения только номер стиха, без повторения OSIS-кода книги и главы.
- Версия 1.3.44 добавляет заголовок при переходе к следующей главе и открывает окна богослужебной библиотеки в полный размер окна чтений.
- Установочный архив 1.3.44 добавлен в `artifacts` и `public/downloads`; серверная сборка публикует его на сайте календаря.
- Стандартное серверное обновление Kalendar всегда выполняет `nodenv local 22`, `npm ci --include=dev` и `npm run build` после fast-forward pull; PHP CLI и общий Plesk PATH не добавляются.
- В плагине разделены русские тропари и кондаки, а список языков ограничивается доступными редакциями.
- Общий рендерер полного произведения и справочного песнопения выставляет `data-orthography` по языку полученной версии: `cu` — Monomakh, `cu-civil` — гражданский шрифт. Отсутствующий `orthography` не переключает `cu` на гражданский шрифт.
- Подготовлен PowerShell-загрузчик немецких текстов Orthodoxia.de и импортный корпус из 19 страниц.

## Текущее состояние и решения

- Ветка разработки: `main`, upstream: `origin/main`.
- Богослужебный корпус и изображения икон фактически обслуживаются API проекта Bible Desktop.
- Долгие скачивания, массовая обработка, импорт и проверки следует выполнять отдельными PowerShell- или серверными скриптами.
- Церковнославянская редакция `cu-civil` является отдельным вариантом отображения и не должна получать традиционный шрифт.
- `cu` и `cu-civil` — отдельные языковые версии; подстановка одной вместо другой и преобразование текста недопустимы.

## Известные проблемы

- Немецкий корпус Orthodoxia.de импортирован с навигационным текстом страниц; все 19 немецких импортов должны оставаться снятыми с публикации до исправления извлечения и сопоставления с существующими произведениями.
- Локально присутствует большой незакоммиченный корпус икон и связанных артефактов. Эти файлы принадлежат текущей пользовательской работе и не должны попадать в посторонние коммиты.
- Публичный Bible Desktop API на 12.09.2026 не содержит `cu` у 38 канонов, 3 акафистов, 14 произведений horologion-appendix и 14 молитв; справочник calendar-texts для `cu` возвращает 0 записей. В Часослове `cu` есть у 21 из 35 произведений. Отсутствующие версии нельзя исправить CSS.
- Знаки икры и полного воздержания общие для всех наборов. При `no-fast` календарь и плагин не выводят картинку поста.
- PHP CLI для локальных проверок найден в `D:/Projekte/Kloster-PAY/tmp/php84/php.exe`; тестовый ini задаёт extension_dir, mbstring, openssl и fileinfo. Локальные WordPress-тесты работают с pdo_sqlite/sqlite3.
