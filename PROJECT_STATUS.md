# Состояние проекта

- Kalendar остаётся редактором печатных календарей: локальное расчётное ядро, макеты, шрифты, общие ссылки, аккаунты, сохранение, история, корзина, PDF и заказы сохранены. Серверный PDF/X запускает Node через отдельный print-runtime.json; календарный HTTP runtime ему больше не нужен.
- Единственный поставщик календарного HTTP API, чтений, богослужебных текстов и икон — Bible Desktop. Веб-календарь обращается к нему напрямую. Календарные обработчики Kalendar, их ключи/тарифы/админка, текстовые посредники и публичный сериализатор удалены; прежние календарные маршруты возвращают 404. Внутренние серверные функции редактора сохранены.
- WordPress-плагин Georg-Kloster Calendar Workshop обновлён до 1.3.71. Сохранены 22 блока, шорткоды, все 16 оформлений и галерея икон. Декоративные изображения, знаки Типикона и лицензированный Monomakh входят в ZIP; старые ключи Kalendar другому поставщику не отправляются. Новые ZIP находятся в artifacts и public/downloads; прежние устанавливаемые ZIP удалены из публикации и сохранены в резервной копии.
- На странице /calendar-api сохранены таблица и загрузки Calendar Workshop, kloster-prayer 1.2.5 и Georg-Kloster Slavonic Translator 1.0.5; документация теперь описывает подключение к Bible Desktop.
- Резервная копия исходников, Git, dist и локальных данных перед миграцией: tmp/backups/Kalendar-20261008-140402, включая проверенный repository.bundle. Копия приватная и не включается в Git. Исходные пользовательские PNG и непричастные файлы не изменялись и не включены в commit.
- Работа согласована с чатами BibleDesktop и my_bible_app. BibleDesktop: f3903f00 (календарные контракты) и 42b03949 (проверенная связь Сергия с календарём), опубликованы владельцем; реальные маршруты и иконы проверены. my_bible_app: 06605359, единый поставщик и 30/30 дней проверены его чатом. Публичный WordPress-репозиторий: 4be11e9 Use Bible Desktop as the sole calendar provider и 74d5e18 Normalize bundled font license whitespace; main отправлен в origin/main.
- Проверки прошли: Vitest 74 файла / 528 тестов; typecheck; production build; HTTP 404 удалённых маршрутов и доступность сеток; аккаунты/сессии/сохранение/история/корзина; заказы и загрузка RGB PDF; настоящий серверный CMYK PDF/X-1a. Браузер редактора создаёт 13 страниц и сохраняет два проекта без обращений к удалённому API. Веб-календарь проверен с фикстурами и настоящим BibleDesktop (украинский день, месяц, служба, проверенные иконы и компактные превью). Документация/ZIP/мобильная ширина и статическая навигация проверены.
- Полный WordPress/SQLite + Edge сценарий прошёл: все 22 режима, 16 оформлений, восемь богослужебных режимов, чтения, галерея, кэш/безопасность/сжатие медиа и оба Gutenberg-предпросмотра без старого ключа.

Новый отдельный сценарий актуального редактора прошёл. Общий набор не объявляется успешным; обновление устаревших сценариев — отдельная задача.

Установка ZIP в WordPress отдельно; её выполнение пока не подтверждено. Отдельный GitHub release/tag и публикация WordPress.org не выполнялись.

XML идентичен; остальное совпало, кроме четырёх памятей 29 февраля в невисокосных юлианских годах: редактор переносит на 1 марта, API пропускает. Практика требует явного переноса на 28 февраля; исправление в этом аудите не реализовано.
