# Исходники оформления

Этот каталог хранит мастер-файлы, которые нужны для повторной сборки ресурсов,
но не должны попадать в `dist` и загружаться на сервер как часть сайта.

- `decor/` — исходные SVG-листы для `npm run assets:decor`;
- `brand/` — полноразмерные исходники экранного логотипа и карточки ссылки.

Печатный логотип остаётся в `public/brand/logo-kalendar.png`, потому что он
встраивается в экспортируемый PDF.
