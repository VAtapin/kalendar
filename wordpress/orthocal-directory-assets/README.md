# Графика календарного плагина для WordPress.org

Подготовлено 13.10.2026 для `georg-kloster-calendar-workshop` в стиле предоставленной владельцем графики плагина записок: тёмно-зелёный узор, золотая рамка, святой Георгий. Отличительный элемент — крупный календарь с переплётом и сеткой дат вместо молитвенного свитка.

| banner-772x250.png | 772×250 | Баннер |
| banner-1544x500.png | 1544×500 | Баннер Retina |

Текст баннера: «Православный календарь», «Праздники, посты и чтения». Значок без надписей, прозрачность снаружи рамки сохранена. Исходные изображения находятся в `source/`.

Генерация: встроенный `image_gen`, два изображения с референсами владельца. Итоговые задания:

1. Квадратный зелёно-золотой значок в стиле референса: сохранить святого Георгия, коня, дракона, красный плащ, храм и золотую рамку; молитвенный свиток заменить заметным настольным календарём с двумя кольцами, сеткой 7×5, крестом и одной красной датой. Без текста; прозрачный фон вне рамки.
2. Широкий баннер в стиле референса: тёмно-зелёный узор, двойная золотая рамка и орнамент; слева новый значок, справа золотая надпись «Православный календарь» в две строки, ниже светлая подпись «Праздники, посты и чтения». Пропорции для WordPress.org 1544×500.

Экспорт в точные размеры выполнен через Sharp; содержание изображений при экспорте не редактировалось. Проверены формат PNG, размеры, лимиты веса и прозрачность значков; баннер и значок 128×128 проверены визуально.

## Публикация

Эти четыре PNG предназначены для **верхнего** каталога `assets/` в SVN плагина, рядом с `trunk/` и `tags/`, согласно [инструкции WordPress.org](https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/). Они не являются runtime-файлами плагина и не требуют нового ZIP или версии.

**Опубликованы 13.10.2026** в WordPress.org SVN assets, revision 3744401. [Публикация](https://github.com/VAtapin/wp_orthodox_calendar/actions/runs/38427103535) завершилась успешно. Все четыре PNG по публичным SVN URL имеют HTTP200 и побайтно совпадают с локальными файлами; SHA-256 сохранены в publication-receipt.json. Баннер визуально проверен по публичному URL. Карточка при немедленной проверке ещё показывала прежнюю графику: обновление кэша не завершено. Скриншоты/readme/runtime/версия плагина не менялись.

Баннер русскоязычный. Если потребуется использовать его только в русском каталоге, при публикации добавить суффикс `-ru_RU` к обоим именам баннеров; английский базовый вариант готовится отдельно.

Deployment Kalendar не требуется: графика хранится вне `public/` и устанавливаемого плагина; серверная сборка сайта её не публикует.
