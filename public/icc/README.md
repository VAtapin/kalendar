Эти ICC-профили извлечены без изменения из архива ECI Offset 2009
`eci_offset_2009.zip`, предоставленного владельцем проекта:

- `ISOcoated_v2_300_eci.icc` — мелованная глянцевая или матовая бумага, профиль по умолчанию;
- `PSO_Uncoated_ISO12647_eci.icc` — немелованная белая бумага;
- `ISOuncoatedyellowish.icc` — немелованная желтоватая бумага.

Профили ECI предназначены для соответствующих условий печати. Если типография
указывает другой CMYK-профиль, пользователь загружает его перед экспортом.
