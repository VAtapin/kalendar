Иконы Богородицы

Все события выбранного дня без сокращений печатной сетки. Выберите дату, язык и профиль — веб-календарь покажет день без API-ключа.

Веб-календарь доступен без регистрации и API-ключа.

Тексты чтений — BibleDesktop

Язык текста выбирается отдельно от языка календаря. Доступные переводы определяются через API BibleDesktop.

Тексты выводятся по номерам выбранного перевода; соответствие нумерации календарному источнику не подтверждено.


  

    

    
Границы данных
Используются те же знаки Типикона, что в календаре. Для обычных памятей знак может отсутствовать. Для икон доступны названия памятей, но не привязанные изображения. Личные календари, фотографии и пользовательские события через этот публичный API не выдаются.
