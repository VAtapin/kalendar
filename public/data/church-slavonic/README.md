каждой формы. Имена в сомнительных коротких полях не используются для печати.

Исправления самого источника записаны отдельно, с исходной формой и основанием,
в [editorial-corrections.json](editorial-corrections.json). В `sources.json`
первоначальные поля источника сохранены без этих исправлений.

В [source-alignments.json](source-alignments.json) перечислены десять отдельно
проверенных соответствий, где русское имя в источнике отличается только знаком
смерти перед тем же годом: `(† 319)` / `(319)`. Имена, числа и чины не удаляются
при сопоставлении; церковнославянское поле сохраняется целиком. Два других
кандидата не включены из-за разницы титулов и неподтверждённой местной орфографии.

Коллекция поставляется отдельно от программного кода редактора. Лицензия всего
редактора этим уведомлением не изменяется. Авторские тексты пользователей не
включаются в коллекцию и не подменяются ею.
