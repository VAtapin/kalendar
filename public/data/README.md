# MemoryDays.xml

`MemoryDays.xml` является единственным импортированным источником календарных
записей. Исполняемый код стороннего плагина в проект не включается.

Контрольная сумма исходного файла:

```text
SHA-256 85A9815F856A920F2E147F62CF2AA1CA4677D79549DE3FF05DE9E26D83E71738
```

Первичный аудит:

- 3811 записей `event`;
- обязательные поля: `s_month`, `s_date`, `f_month`, `f_date`, `name`, `type`;
- 138 записей содержат `discription`;
- ссылки в текущем файле отсутствуют;
- 4 полных дубликата;
- 89 записей используют специальные отрицательные значения `s_month`;
- 1156 записей полностью привязаны к Пасхе;
- 2564 записи используют фиксированные даты по старому стилю;
- 2 записи начинаются относительно Пасхи и заканчиваются фиксированной датой.

Парсер сохраняет исходные строки и одновременно создаёт нормализованную
типизированную запись. Неизвестные поля не отбрасываются без диагностики.
