Проверка календарного API

Все события выбранного дня без сокращений печатной сетки. Один файл HTML: можно открыть двойным щелчком или разместить на любом сайте.

Нужен интернет и опубликованный API. Вход в кабинет и API-ключ не требуются. При отсутствии перевода сохраняется русский текст с явной пометкой.

Границы данных

Используются те же знаки Типикона, что в календаре. Для обычных памятей знак может отсутствовать. Для икон доступны названия памятей, но не привязанные изображения. Личные календари, фотографии и пользовательские события через этот публичный API не выдаются.
