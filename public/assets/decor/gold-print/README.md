# Золотой печатный декор

В каталоге находятся 18 самостоятельных PNG-элементов, созданных встроенным
ImageGen по предоставленному пользователем листу-референсу. Референс использован
только для художественного направления: каждый объект сгенерирован отдельно.

Общий набор указаний для генерации: один изолированный ажурный орнамент для
православного печатного календаря; полированное гравированное золото, выраженный
металлический объём, тёплые блики, умеренный блеск и аккуратная мягкая тень;
подлинный прозрачный альфа-канал; без фона, шахматной подложки, текста, водяных
знаков, обрезки и дополнительных предметов. Для углов, разделителей, розеток,
креста и вертикальных украшений отдельно задавалась соответствующая геометрия.

Все файлы содержат метаданные 300 dpi (`pHYs`: 11811 пикселей на метр по обеим
осям). Исходные размеры составляют от 1024 × 1536 до 2172 × 724 пикселей.
