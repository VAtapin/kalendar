This is a starter catalogue, not complete coverage of the calendar year.
`metadata.completeness.iconImages` remains false. An absent image is represented by
`imageUrl: null` for commemorations of icons; saints with no reviewed image do not
produce an image entry. Relative image paths are resolved against the API origin.

To add an image, review the depicted person/feast and the source license, place
the permitted file here, record its credit, and add an exact source ID + source
title association in `src/calendar/api/icon-catalog.ts`. Do not match translated
names or assign a different saint when an image is unavailable.
